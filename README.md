# Milestone 2: Formula 1 Knowledge Graph
### Documentation and Libraries
- Useful documentation for neo4j python: https://neo4j.com/docs/python-manual/current/
- make sure you install python package `neo4j`
- make sure you install python package `dotenv`
### Important Notes:
- make sure you install **neo4j desktop** to be able to connect to local URI `from config.txt`
- make sure the instance you create has the same username and password as in `config.txt`
- DO NOT CHANGE the contents of `config.txt`
- DO NOT CHANGE the contents of any `.csv` files
- DO NOT CHANGE the names of any files
